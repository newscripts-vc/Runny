# Runny
this proyect is eating my life.

This project consists of a robot designed for basic education for children aged approximately 6 to 14. Its function is to assist in the formation of basic concepts, such as natural numbers (0 to 9), primary colors, the letters of the alphabet (A-Z), and some simple words to aid in speech development.
The robot has a friendly humanoid silhouette, primarily inspired by the Nao prototype. It will feature an OLED screen displaying all necessary information, as well as speakers on the sides of its head, creating the illusion of "ears," so the user can hear what the robot is saying. Its movement is based on a wheel system, simplifying its construction and protecting the prototype if used on elevated surfaces, preventing accidental falls and damage to its system.
Children up to 14 years old will have the option to reprogram the robot, adding more words, numbers, letters, and colors. This reprogramming can also help them establish a direct connection to programming using three different languages. This reprogramming includes different languages that increase in difficulty depending on the user's choice, ranging from block-based programming like Scratch, to C++ programming, and finally to Python programming.
